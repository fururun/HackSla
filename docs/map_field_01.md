# 広いマップ（field_01）の設計

`data/maps/field_01.txt`（74×52 マス）。作り方は `python tools/maps/make_field_01.py`（部屋と通路の位置・印の位置は、そのスクリプトの先頭で直す）。
メイン画面は `scripts/main/main.gd` の `MAP_PATH` でこのマップを読む。小さなテスト用マップ `test_01.txt` は残してある。

## 印

| 印 | 意味 |
| --- | --- |
| `P` | 開始位置 |
| `D` | 案山子（倒れない的） |
| `C` | 宝箱（近づくと開く。まとまった数のドロップ） |
| `f` | 小さなスライムの群れ（5匹。`main.gd` の `SMALL_PACK_SIZE`） |
| `s` | スライムの群れ（8〜14匹。`data/enemies/enemies.json` の `pack`） |
| `b` | 岩殻（1体） |
| `L` | レジェンドの宝箱の候補（4か所）。毎回、ごくまれ（3%）に、このうち1か所に、金色の宝箱が置かれる |
| `r` | 毒吐きスライム（遠くから弾を撃つ。2〜3匹の群れ） |

## 構成：廃寺の地下墓所（分岐と周回）

一本道をやめて、中心の境内（中庭）から道が分かれ、ぐるっと回れる作りにした。旧マップ（四角と八角形の部屋が一本道）は `data/maps/field_01_old.txt`（作り方は `tools/maps/make_field_01_old.py`）に残してある。使いたいときは `main.gd` の `MAP_PATH` を、そちらに変える。

| 場所 | 形・役目 | 敵 | 宝箱 |
| --- | --- | --- | --- |
| 開始の広場（参道の入口） | 八角形。案山子2つ | なし | 1 |
| 山門 | 小さな門の間 | 小さな群れ ×1 | レジェンド箱の候補 |
| 境内（中庭） | 大きな八角形。石灯籠の柱が6本 | 群れ ×2、小さな群れ ×1、遠距離 ×2 | レジェンド箱の候補 |
| 鐘楼 | 北東の小部屋 | 小さな群れ ×1 | 1 |
| 僧坊 | 西の部屋 | 小さな群れ ×1 | 1 |
| 回廊 | 本堂を囲む環状の廊下（周回の中心） | 群れ ×3 | なし |
| 本堂 | 回廊の内側の小部屋（北の戸から入る） | 岩殻 ×1 | 1、レジェンド箱の候補 |
| 墓所 | 東の大きな丸い広場。墓石の柱 | 岩殻 ×1、遠距離 ×2 | レジェンド箱の候補 |
| 奥の広間 | 南の広間。柱が並ぶ。最後の大きな戦い | 群れ ×2、岩殻 ×1、遠距離 ×1 | 1 |
| 奥の院 | 左下の大きな丸い広場。ボス | ボス | なし |

周回の道：
- 開始の広場 → 僧坊 → 回廊 → 境内 → 山門 → 開始の広場
- 境内 → 鐘楼 → 墓所 → 回廊 → 境内
- 回廊 → 墓所 → 奥の広間 → 回廊

奥の院に入れる道は、奥の広間の西の端から伸びる通路だけ（開始からの最短は 107 歩）。
自動戦闘（F2）で、全部の敵を倒し、全部の宝箱を開け、ボスまで回れることを、`tools/autoplay_check.gd` で確認した（約 4.5 分。Lv7）。

## 経験値の見積もり

スライム 3、岩殻 18。次のレベルまでに必要な経験値は `20 × レベル^1.5`（Lv2 まで 20、Lv3 まで 57、Lv4 まで 104、Lv5 まで 160。合計 Lv5 まで 341）。

- スライム：約 97 匹（群れの数は旧マップと同じ）（f 4群×5 + s 7群×平均11）× 3 = 約 291
- 岩殻：3体 × 18 = 54
- 合計：約 345 → 全部倒すと Lv5 に届く（自動戦闘の確認では、ボスまで倒して Lv7）

## 調整のしどころ

- 敵が強すぎる・弱すぎる：`data/enemies/enemies.json`（`life` `damage` `speed` `aggro_range`）
- 群れの数：`main.gd` の `SMALL_PACK_SIZE`、`enemies.json` の `pack`
- 体力の自然回復：`scripts/player/player_consts.gd` の `LIFE_REGEN_PER_SEC`（いまは 1秒に 1.5）
- 部屋の大きさ・敵の位置・宝箱の数：`tools/maps/make_field_01.py` を直して、もう一度実行する

## （旧マップの）部屋の形

四角だけの部屋をやめて、形に変化をつけた（印の数・順番・経験値の見積もりは変えていない）。

| 部屋 | 形 |
| --- | --- |
| 開始の広場 | 角を落とした八角形 |
| 部屋A | 楕円の広間。柱3本 |
| 部屋B | 八角形。柱3本 |
| 部屋C | 丸い広場 |
| 広場E | 角を少し落とした広間。柱が並ぶ（8本） |
| ボスの部屋 | 大きな丸い広場。柱4本 |
| 横道の小部屋 | 小さな八角形 |

形は tools/maps/make_field_01.py の carve_oct（八角形）・carve_ellipse（楕円）・pillar（柱）で作る。
