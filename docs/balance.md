# プロトタイプ（P0）数値バランス設計書

本ドキュメントは、タスク T12 にて設定したプロトタイプ（レベル1〜10：序盤〜中盤の入り口）の初期数値、その設定理由、1秒あたりダメージ（DPS）比較、撃破時間（TTK）の見込み、および企画上の各目安の達成状況をまとめたものです。

## 2. 各データの設定値と理由

### 2.1 スキル（`data/skills/skills.json`）

解像度 `480×270`・キャラ身長約 `20` ドット・斜め見下ろし距離（`Iso.ground_distance`）を基準に設定しています。

| id | 名前 | 属性 / 種類 | ダメージ (平均) | 再使用 (秒) | 射程 / 半径 / 弾速 | 設定理由 |
| --- | --- | --- | --- | --- | --- | --- |
| `slash` | 斬撃 | `physical` / `melee` | `[14, 22]` (`18.0`) | `0.5` | `26` / `22` / `0` | 基本の近接技。前方扇形48ドット（`range + radius`）に届き、群れ小鬼（HP 20）を1〜2回で斬り伏せる。単体DPSは `36.0` で、岩殻（HP 360）に対してちょうど10秒かかる基準値となる。 |
| `frost_bloom` | 氷華 | `cold` / `area` | `[10, 14]` (`12.0`) | `0.8` | `0` / `48` / `0` | 自分の周囲48ドットを凍らせる範囲技。群れ小鬼を1発では倒さず（残HP 6〜10）、2発（計1.6秒）で確実に一掃できる。また1発当てた直後に斬撃へ繋ぐことで「砕氷」の起点になる。 |
| `fire_bolt` | 火球 | `fire` / `projectile` | `[18, 26]` (`22.0`) | `0.5` | `220` / `5` / `240` | 画面端近く（220ドット）まで届く高速の単体飛び道具。単体DPSは `44.0` と斬撃より高いが、そのままでは1体ずつしか倒せないため「拡散」ジェムを付けた際の群れ殲滅力の変化が際立つ。 |
| `shatter` | 砕氷 | `cold` / `melee` | `[72, 96]` (`84.0`) | `0.4` | `28` / `42` / `0` | 氷華→近接で発動するチェイン専用の大技。斬撃の **4.67倍** の単発威力と広い範囲（計70ドット）を持ち、群れの吹き飛ばしにも岩殻の突破にも「積極的に出したくなる」決定力を持つ。 |

### 2.2 補助ジェム（`data/supports/supports.json`）

| id | 名前 | 対象 (`kinds`) | 補正 (`modifiers`) | 設定理由 |
| --- | --- | --- | --- | --- |
| `scatter` | 拡散 | `["projectile"]` | `projectile_count: 2`<br>`damage_mult: 0.85` | 飛び道具を3方向に増やす。`damage_mult` を `0.85` に設定することで、単体相手（1発命中）では元の85%と「ほぼ同じか少し弱い」水準に留めつつ、群れ相手（3発命中）では元の **255%** という圧倒的な強さを実感できる。 |
| `burst_on_kill` | 撃破時爆発 | `[]`（全スキル） | `explode_on_kill: 0.6`<br>`explode_damage_ratio: 1.5` | 撃破時に60%の確率で最大ライフの150%ダメージを与える。群れ小鬼（HP 20）が爆発すると周囲に **`30` ダメージ** を与えるため、隣接する群れ小鬼（HP 20）を1撃で誘爆させて連鎖し、近くに岩殻がいた場合も大ダメージを与えて撃破時間を半分以下に短縮する。 |

### 2.4 装備・レアリティ・付与効果（`data/items/`）

- **レアリティ（`rarities.json`）**：重み合計を `2000` に統一。
  - `common`（重み `1300` / **65.0%** / 付与 `0`個）
  - `uncommon`（重み `500` / **25.0%** / 付与 `1〜2`個）
  - `rare`（重み `165` / **8.25%** / 付与 `2〜3`個）
  - `epic`（重み `31.5` / **1.575%** / 付与 `3〜4`個）
  - `legend`（重み `3.0` / **0.150%** / 付与 `4〜5`個 / `beam: true`）
  - `myth`（重み `0.5` / **0.025%** / 付与 `5〜6`個 / `beam: true`）
- **装備の土台（`bases.json`）**：レベル1からドロップする6種（`iron_sword`, `oak_staff`, `leather_vest`, `cloth_hood`, `worn_boots`, `copper_ring`）の素の性能を、装備した瞬間に火力や生存力の変化が分かる値（ダメージ+12%、範囲+10%＋詠唱速度+5%など）に調整。
- **付与効果（`affixes.json`）**：既存の10種の `id` を維持しつつ、`AffixDef.STATS` の全14ステータスを網羅する **計15種類** に拡充。どの部位（`weapon`, `armor`, `helmet`, `boots`, `ring`, `amulet`）でも最低9種類以上の付与効果が抽選対象となるため、最大6個の付与効果がつく `myth` でも重複なし抽選が確実に成立する。

## 5. タスク T22 追加データ（スキル5種＋チェイン1種・補助ジェム4種）の狙いと数値根拠

## マナ（スキルの消費）

- プレイヤーは、最大マナ 100、自然回復 毎秒 22 から始まる。スキルを使うたびに、コストのマナを払う。足りないときは、スキルが出ない（再使用時間も始まらない）。
- コストは、威力にほぼ比例（平均ダメージの 0.25〜0.3 倍）：払い 3、火花の矢 3、氷華 5、火球 5、火の輪 5、氷の欠片 5、突き 6、地面叩き 8。チェイン技は 0（元のスキルの分を払う）。
- 補助ジェムは、コストの倍率が付く：拡散×1.3、連続使用×1.35、重ね乗せ×1.2、跳び移り×1.2、撃破時爆発×1.15、範囲広げ×1.1。
- 装備の付与効果に「最大マナ（+15〜40）」と「マナ回復（毎秒 +3〜8）」。レベルアップで、ライフと一緒に満タンになる。
- 狙い：序盤は、マナを意識せずに撃てる。補助ジェムを重ねたり、撃つ数が多い構成にすると、マナが効いてくる。
- 20秒の案山子で測った、自動戦闘のDPS（マナなしを100%）：3種類の構成で 80〜100%（平均約88%）。マナの消費は、毎秒 21〜31 で、回復 22 とほぼ釣り合う。
- 調整の数字：`scripts/player/player_consts.gd`（最大・回復）、`data/skills/skills.json`（mana_cost）、`data/supports/supports.json`（mana_mult）。

## チェイン技の追加ダメージ（絵が出た場所）

- チェイン技が出ると、少し（0.12秒）遅れて、絵が出る場所（狙った先）に、輪が出て、中の敵に追加のダメージが入る。
- 半径は、その技の半径（最低36）。ダメージは、その技のダメージの 0.5 倍（補助ジェムの倍率つき）。足元の技の円・近接の範囲とは、別。
- チェイン技の割合は、ダメージ全体の約35〜40%なので、全体のDPSは、群れ相手で、1〜2割ほど上がる見込み。強すぎたら `combat_consts.gd` の `CHAIN_AFTERSHOCK_RATIO` を下げる。

## スキルツリー（`data/skill_tree/skill_tree.json`）

- 46ノード（根源1 ＋ 小ノード31 ＋ 中ノード10 ＋ 大ノード4）。全部取るには 63 ポイント（レベル64）。レベルは最大100。
- 方角：東＝火力（ダメージ%・近接/飛び道具/範囲）、西＝生存（ライフ・防御）、北＝元素（火・冷気・雷。各3個の列）、南＝マナ・補助・チェイン。
- 数値の物差し：装備の付与効果1つが「ダメージ+16〜32%」「ライフ+19〜45」「マナ+15〜40」。ツリーは、小ノードで装備の付与効果の **約 1/4**（ダメージ+5%、ライフ+12、マナ+12）、中ノードで **同じくらい**（ダメージ+15%、元素+28%、チェイン+40%）にして、装備を主役のままにする。
- 1回のプレイ（スタートからボス）で上がるレベルは、バランス記録（91回）で平均 6.4・最大 7。つまり、1周で貯まるのは約 6 ポイント。小ノードを2〜3つと中ノードを1つ取れる量で、最初の中ノード（剛力：ダメージ+15%）に届く。
- 大ノードは、強い代わりに縛りがある：硝子の大砲（ダメージ+40%・ライフ-40）、不屈（ライフ+80・防御+40・ダメージ-15%）、元素の覚醒（元素ダメージ+20%×3・防御-20）、連鎖の申し子（チェイン+60%・マナ消費+25%）。自動戦闘は、大ノードを取らない。
- マナ・チェインとの兼ね合い：マナ消費の軽減は -6% ×2 ＋ 大ノードの +25% で、全部取っても元の 60% までに収まる（下限は 40%）。チェインのダメージ%は、追加ダメージ（0.5倍の輪）にも乗るが、小15 ×2 ＋ 中40 ＝ +70%（大ノード込みで +130%）止まりで、チェインが全ダメージの約35〜40%という前提を崩さない。補助ジェムのダメージ%は、補助つきのスキルにだけ乗る（小8×2 ＋ 中25 ＝ +41%）。
- 自動戦闘（F2）が入っている間は、貯まったポイントを、データの順（先に取れるノード）で自動で使う。足りないときは、飛ばさずに貯める。手で遊ぶときは、T で画面を開いて自分で選ぶ。

## リスタート（リセットと、引き継いでリスタート）

| | リセット（F5） | 引き継いでリスタート（F9） |
| --- | --- | --- |
| レベル・経験値 | 1 から | 持ち越す |
| スキルツリー | 何も取っていない | 取ったノードも、使っていないポイントも、持ち越す |
| 装備（各部位） | なし | 持ち越す（`RunCarry.KEEP_EQUIPMENT`） |
| スキルジェム・補助ジェム | スタート構成（ランダムな3つ）と、はじめの補助ジェム | 同じ（持ち越さない。スタート構成は、毎回ランダム） |
| 通貨・回復の回数・敵・宝箱・ドロップ・マップ | 最初から | 最初から |
| ライフ・マナ | 満タン | 満タン（ツリーと装備の効果込み） |

- **ツリーの扱い**：ポイントを返却する案ではなく、取った状態のまま持ち越す。理由：引き継ぎは「育てたものを持って、もう一周する」ための選択肢で、返却すると、毎周、同じノードを取り直す手間が増えるだけだから。ツリーを組み替えたいときの振り直しは、別の機能として後で入れる。
- 自動周回（ボス撃破・やられたとき）は、これまでどおり **リセット**（毎周、同じ条件で比べられる）。`AutoLoop.restart_mode` を `CARRY` にすると、引き継いで周回する。
- 強さの見込み：レベルを持ち越すと、次のレベルまでの経験値も大きいまま。1周で稼ぐ経験値は約 900 なので、レベル7から始めると、2周目で上がるのは約 2〜3レベル（ポイント +2〜3）。引き継ぎを続けても、1周あたりの伸びは小さく、ツリーが埋まるのに時間がかかる。そのかわり、装備を持ち越すので、拾った強い装備は残る。強すぎたら、まず `RunCarry.KEEP_EQUIPMENT` を `false` にする。
- バランス記録（`balance_logs/runs.jsonl`）に、`restart`（`mode`：`reset` / `carry`、`carry_depth`：連続で引き継いだ回数、`start_level`：始めたときのレベル）と、`tree`（取ったノード・使ったポイント・余り）が入る。引き継ぎの周は、`restart.mode` で分けて集計する。
- 効かないステータス（耐性・範囲%・移動速度%）は、ゲーム側がまだ読んでいないので、ツリーには入れていない。
