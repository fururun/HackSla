本ドキュメントは、本作（HackSla）のスキルツリー（T19）・補助ジェム・アイテムフィルターを設計するにあたり、『Path of Exile 2』（以下 POE2）および先行事例『LUMINA CUBE（ルミナキューブ）』の「なぜ面白いか」「どこで混乱が生じるか」の仕組みを分析し、本作向けに再構築するための設計資料である。

### 仕組みの分析と「プレイヤーが何を楽しんでいるか」

| 要素 | POE2の仕組み | プレイヤーが何を楽しんでいるか（面白さの芯） |
| --- | --- | --- |
| **枝の分かれ方** | 中央付近から放射状に幹線（トラベルノードの道）が伸び、幹線の途中に「クラスター（4〜8個程度の小・中ノードの塊）」が枝分かれして配置される。外周に向かうほど専門性が高まり、別方向の幹線とも環状に繋がる。 | **「ルート開拓の計画性」**：目的地（欲しい大・中ノード）に向けて最短で直行するか、道中の美味しい枝（クラスター）に寄り道するかという「限られたポイントの投資判断」を楽しんでいる。 |
| **ノードの密度と役割分担** | ①道を作る「属性・移動用小ノード」、②クラスター入口〜中腹の「テーマ別小ノード」、③クラスター奥にある「中ノード（Notable：明確に強い効果）」、④外周や独立位置にある「大ノード（Keystone：ルール変更）」の4階層で構成される。小ノード3〜5個につき中ノード1個程度の密度（正確な全体比率は未確認）。 | **「日々の小さな成長と、節目の大きな達成感のリズム」**：毎レベルの1ポイントでは「あと2つで中ノードに届く」というワクワク感を維持し、中・大ノード到達時に「一気に強くなった・動きが変わった」というご褒美（パワースパイク）を得られる。 |
| **大ノード（Keystone）の縛りの付け方** | 「強力なメリット」と「明確なデメリット（または特定要素の無効化・変換）」をセットにする。例：「特定属性ダメージを完全無効化する代わりに最大ライフが1になる」「クリティカルが出なくなる代わりに素の命中・ダメージが安定する」など、ゲームの計算ルール自体を書き換える。 | **「デメリットを踏み倒すパズル（ビルド構築）」**：「普通に取ると損をする縛り」を、他の装備・スキル・中ノードとの組み合わせで「自分にとっては実質ノーリスク（あるいはメリット）」に変える逆転の発想を楽しんでいる。 |
| **属性・テーマによる方向分け** | ツリーの方角ごとに得意な属性・戦い方のテーマ（例：北は知性・魔法・冷気/雷、南東は敏捷・投射物・速度、南西は筋力・近接・装甲・火など）が分かれている。また、道中の属性小ノードはプレイヤーが3属性から任意に選択・変更できる仕組みを持つ。 | **「直感的な地図の理解と、越境のロマン」**：「自分のビルドならこの方角を目指せばよい」と直感的に理解できる安心感と、あえて遠い方角の要素を混ぜて独自のハイブリッドビルドを作る楽しさの両立。 |
| **振り直しの仕組み** | ゲーム内通貨（ゴールド）をNPC（The Hooded One等）に支払うことで1ノード単位で払い戻し可能。コストはキャラクターレベルに応じて上がるが、序盤は安価で試行錯誤しやすく、終盤もゲーム内通貨の収集で現実的にやり直せる（かつ末端から順に外す接続制約がある）。 | **「取り返しがつく安心感と、選択の重みの両立」**：序盤の失敗を恐れずに色々試せる安心感がありつつ、完全にタダではないため「よく考えて振る」「新しい装備を拾ったからまとまった通貨を払ってツリーを組み替える」というイベント感が生まれる。 |

## 2. 補助ジェム（サポートジェム）

### 出典URL
- Path of Exile 2 Wiki (Fextralife) — Support Gems: https://pathofexile2.wiki.fextralife.com/Support_Gems
- Mobalytics — Path of Exile 2 Patch 0.3 Support Gem Changes: https://mobalytics.gg/poe-2/guides/0-3-support-changes
- Maxroll — Path of Exile 2 Hub & Guides: https://maxroll.gg/poe2

### 仕組みの分析

1. **付けられる条件（タグと種類の整合性）**
   - スキルジェムごとに「属性（Fire, Cold, Lightning, Physical等）」や「挙動の種類（Projectile, Area, Melee, Duration等）」のタグが付与されている。
   - 補助ジェム側にも対応タグ・前提条件があり、「飛び道具（Projectile）タグを持つスキルにしか『拡散』は付けられない」「近接や範囲にしか付かない」といったルールで不整合を防いでいる。
   - UI上でも、ある補助ジェムを選択した際に「現在装備中のどのスキルに装着可能か」が即座に判別できるようになっている。

2. **付けたときの挙動の変わり方（数値強化よりも「見た目と手触り」の変化）**
   - 単に「ダメージ+20%」のような見えない数値強化だけでなく、**画面上の挙動が変わる**ものが主役になっている。
   - 例：弾が1発から扇状3発に増える、敵に当たった後に別の敵へ連鎖（Chain）する、凍結させた敵を倒すと爆発して周囲を巻き込む、範囲が劇的に広がる代わりに発生が遅くなる、など。
   - これにより、補助ジェムを1つ差し替えるだけで「1体ずつ倒す技」が「群れを一掃する技」へと役割そのものが変化する。

3. **強すぎる組み合わせの抑え方（バランス調整の仕組み）**
   - **トレードオフ倍率（倍率ペナルティ）**：弾数が増える・範囲が広がる・連鎖するといった手数・範囲系の補助ジェムには、「1発あたりのダメージ 0.7倍」「クールダウンやコストの増加」といったマイナス倍率がセットで設定されている。
   - **同一スキル内での重複禁止**：同じ種類の補助ジェムを1つのスキルに2個同時に挿すことはできない。
   - **（重要・反面教師）キャラ全体での「同名補助ジェム1個制限」とその撤廃**：POE2はアーリーアクセス初期、「プレイヤーが全スキルに同じ最強補助ジェムばかり付けるのを防ぐ」目的で「1キャラにつき同じ補助ジェムは1つしか装備できない」という制限を設けた。しかし、これが「複数スキルの連携や自由な試行錯誤を窮屈にする」「付け替えの手間が増える」と大きな不評を買い、パッチ0.3.0で撤廃され、代わりにティア制（段階的な上位版）へと改修された。
   - **連鎖的な無限ループの防止**：「爆発で発生したダメージではさらに同じ爆発を誘発しない」といった再帰制限や確率・クールダウンの制限を設けている（詳細な内部判定式の一部は未確認）。

## 3. アイテムフィルター

### 出典URL
- Path of Exile Official — Item Filter Guide: https://www.pathofexile.com/item-filter/about
- GitHub — NeverSink-Filter-for-PoE2: https://github.com/NeverSinkDev/NeverSink-Filter-for-PoE2
- Maxroll — Path of Exile 2 Build Guides & Loot Filter Integration: https://maxroll.gg/poe2/build-guides

### 仕組みの分析

1. **何で絞れるか（フィルタリングの条件軸）**
   - **レアリティ（Rarity）**：ノーマル / マジック / レア / ユニークなどの段階（`>= Rare` のような比較演算を含む）。
   - **アイテム種別・部位（Class / BaseType）**：通貨、ジェム、武器・防具・装飾品の各部位、および装備の土台（ベースアイテム）の種類。
   - **レベル条件（ItemLevel / DropLevel / AreaLevel）**：落ちたアイテムのレベル、その土台が出始める要求レベル、現在いるマップ（階層）のレベル。
   - **アイテム固有の性能値**：ソケット数や品質など（本作では「付与効果の数」や「特定の付与効果（stat）の有無」に置き換え可能）。
   - **表示アクションの切り替え**：単に「表示（Show）/ 非表示（Hide）」の2択ではなく、文字サイズの拡大、文字色・背景色・枠線の変更、ミニマップアイコンの表示、ドロップ時の効果音と光の柱（PlayEffect）の有無を段階的に制御できる。

2. **初心者向けの既定の絞り方（デフォルトおよび低Strictnessの設計）**
   - NeverSink等の定番フィルターにおける初心者・序盤向け設定（Soft / Regular）では、**「最初はほぼすべて見せ、進行度（AreaLevel）に応じて自然に足切りラインを上げる」**設計になっている。
   - **序盤**：ノーマルやマジック装備も装備更新に使うため表示する。ただし価値の高いジェム・通貨・レア以上の装備は文字枠や色を変えて目立たせる。
   - **中盤以降**：現在の階層レベルに対して「土台レベルが低すぎるノーマル・マジック装備」から順に自動で非表示（または文字を小さく半透明化）にし、画面がゴミ装備のラベルで埋め尽くされるのを防ぐ。
   - **絶対に見逃させないもの**：最上位レアリティやジェム、クラフト素材はどの段階でも必ず「大きな文字＋特別な色＋光の柱＋専用効果音」で強調表示する。

## 4. このゲーム（HackSla）への提案

### 出典URL
- itch.io — LUMINA CUBE（ルミナキューブ）公式ページ（約170個の星からなる「星図」システムの先行事例）: https://yurukusa.itch.io/luminacube

### 4-1. ノード数150〜200でPOE2と同じ楽しさを出すための「残すもの・削るもの」

本作は最大レベル100（約99ポイント）に対し、ツリー全体を **150〜200ノード** に収める（全体の約50〜65%を取得可能）。数千ノードあるPOE2の感覚をそのまま縮小すると「ただの1本道」になるため、以下のように取捨選択する。

#### 【残すもの（面白さの芯）】
1. **「小ノード2〜3個 → 中ノード1個」のクラスター構造**
   - 3〜4レベルごとに「戦い方が目に見えて変わる中ノード（範囲拡大、チェイン強化、撃破時回復など）」に到達できるテンポを残す。
2. **メリットと縛りがセットの「大ノード」（全ツリーで8〜12個程度）**
   - 「クールダウンがなくなる代わりにダメージ減」「直撃ダメージが減る代わりにチェイン技の威力が跳ね上がる」「最大ライフが減る代わりに防御や属性耐性が大幅上昇」など、ビルドの軸を決める大ノードを各枝の奥や外周に配置する。
3. **方角によるテーマ分けと、枝同士を繋ぐ「環状ルート（渡り廊下）」**
   - 中央から4〜6方向（例：物理・近接／火・範囲／冷気・制御／雷・連鎖／速度・投射物／生存・防御）に枝を伸ばし、隣り合う枝の中腹同士を繋ぐルートを作ることで、「火と冷気のハイブリッド（チェイン特化）」のようなルート選択を楽しめるようにする。
4. **ゲーム内通貨による手軽な振り直し**
   - 末端ノードから1ポイントずつ、手持ちの通貨でいつでも振り直せる仕組み。

#### 【削るもの（150〜200ノードに圧縮するために捨てる要素）】
1. **単なる「移動のためだけの長い通路（トラベルノードの連続）」**
   - POE2では中ノードに辿り着くまでに5〜7個の移動ノードを踏ませることがあるが、150〜200ノード規模では小ノードは「分岐から中ノードまでの1〜3歩」に留める。
2. **スキル装備枠やシステム解放用のノード**
   - 先行事例『ルミナキューブ』では約170ノードの星図の中に「回路の段を増やす（システム枠を広げる）星」が混在していたが、本作の企画通り**ツリーは純粋なステータスとパッシブ専用**とし、スキル枠・補助枠の解放はレベル節目やボス報酬に分離する。
3. **細かすぎる条件付き微小ボーナス**
   - 「特定の狭い状況下でだけ+3%」のような実感しにくいノードは削り、本作の `data/items/affixes.json` や `supports.json` にある軸（ダメージ%、属性ダメージ%、範囲%、速度%、クールダウン短縮%、耐性%、撃破時効果、チェイン倍率）と直結する分かりやすい効果に絞る。
4. **「キャラ全体で同じ補助ジェム1個まで」の制限**
   - POE2が初期に失敗した「別スキル間での同名補助ジェム制限」は入れず、1つのスキル枠の中に同じ補助ジェムを2つ入れられない制限だけにする。

#### 【ノード配分の目安（全180ノードの場合の試案）】
- **小ノード（約120個）**：ライフ、防御、ダメージ%、速度%、属性ダメージ%など（1歩ごとの着実な基礎強化）
- **中ノード（約48個・12クラスター×4方向など）**：範囲拡大、チェインダメージ強化、撃破時ライフ回復、属性耐性+最大値など（3〜4レベルごとの目標）
- **大ノード（約12個）**：強いメリット＋縛り（ビルドの完成形を決める目標）

### 4-2. 情報量でプレイヤーを混乱させない「段階的な解放の順番」

『ルミナキューブ』で起きた「約170ノードの星図や複数のカスタム要素が最初から一度に見えてしまい、何をすればいいか分からなくなる」問題を防ぐため、**UIの見た目と要素の解放を成長の4段階に合わせて段階化する**。

| 段階 | レベル目安 | 解放する要素と「見せる範囲」の制御 | プレイヤーの意識 |
| --- | --- | --- | --- |
| **1. 序盤（導入）** | Lv 1〜5 | **・スキル枠2、補助枠0〜1から開始**<br>**・ツリーの「霧（フォグ）」表示**：最初は中央スタート周囲（半径2〜3歩・約20ノード分）だけが見えており、外側は暗い霧で隠す。ノードを取るにつれて周囲の霧が晴れて先の枝と中ノードが見える。<br>**・ドロップフィルターは「すべて表示」** | 「まずは基本スキルで敵を倒す」「目の前の3択の枝から1つ選んで最初の中ノードを取る」だけに集中できる。 |
| **2. 中盤の入り口** | Lv 6〜15 | **・補助枠の追加とスキルチェインの発見**<br>・ツリーの中腹（最初の大ノードのシルエット）が見えてくる。<br>・スキルチェインが初めて発動した時点で「チェイン図鑑」を解放する（最初から全リストを見せない）。 | 「補助ジェムで技の広がり方が変わる面白さ」「2つのスキルを繋ぐチェインの気持ちよさ」を順番に学習する。 |
| **3. 中盤** | Lv 16〜40 | **・ツリー全体の霧が晴れ、全貌（150〜200ノード）と大ノード群が見渡せるようになる（手動で「全体を見る」トグルも用意）**<br>・振り直し機能の案内。<br>・ドロップが増えるため、**簡易アイテムフィルター（ワンタッチ切り替え）**を解放。 | 「大ノードを目指してビルドを組む」「大量のドロップからフィルターで良品だけ拾う」ハクスラ本来のサイクルに入る。 |
| **4. 終盤** | Lv 41〜100 | **・スキル枠6・補助枠4〜5（最大）**<br>・装備クラフト（付与効果の振り直し・追加・固定）と、フィルターの細かな条件設定（欲しい付与効果の強調など）を解放。 | 複数の大ノードとチェイン・補助ジェム・クラフト装備を噛み合わせ、無限ダンジョンの深層へ挑む。 |

### 4-3. 本作向けの簡易アイテムフィルター設計案
POE2のようなテキストスクリプト記述は不要とし、ゲーム内UIで直感的に切り替えられる**3段階プリセット＋チェックボックス**を提案する。
- **プリセット1「すべて表示（序盤向け）」**：すべての装備・ジェムを表示。
- **プリセット2「おまかせ選別（中盤向け・推奨）」**：ノーマル装備や、現在階層より大幅にレベルの低い土台を非表示。マジック以上とジェムを表示。
- **プリセット3「厳選（終盤向け）」**：レア以上（または特定の欲しい部位・付与効果を持つもの）とジェムのみ表示。
- ※最上位2段階のレアリティ（`beam: true`）と未所持ジェムは、どのプリセットでも常に光の柱と専用音で強制表示する。
