# プロトタイプ（P0）の範囲

「この遊びの芯が気持ちいいか」だけを確かめる、小さなプロトタイプ。作り込まない。

## 確かめること（成功の条件）

1. 斜め視点で群れをまとめて倒すのが気持ちいいか
2. 補助ジェムを付け替えたら、強くなった実感があるか
3. 敵100〜150体を同時に出しても60fpsが出るか
4. スキルチェイン（砕氷）が気持ちいいか。受付無制限の操作感がストレスにならないか

## 入れるもの

| 内容 | 状態 |
| --- | --- |
| テスト用マップ（広場・通路・敵の広場）`data/maps/test_01.txt` | できた |
| プレイヤー：8方向移動、マウス方向への斬撃 | できた |
| 案山子（倒れない練習用の的、DPS表示） | できた |
| データの型と読み込み、スキルチェインの判定 | できた |
| 敵2種類（群れ小鬼・岩殻）とその動き | T06・T08 |
| スキル3つ（斬撃・氷華・火球）＋チェイン技（砕氷） | T10 |
| 補助ジェム2つ（拡散・撃破時爆発） | T10 |
| 簡易スキル装備画面（スキル枠2、補助枠各1） | T11 |
| ドロップ（ジェムと、付与効果1〜2個の装備） | T14 |
| 経験値とレベルアップ | T09 |
| ヒットストップとダメージ数字 | T18 |
| 数値の初期値 | T12 |
| デバッグ用の操作（FPS表示、敵の呼び出し） | T17 |

## 入れないもの

スキルツリー、クラフト、ドロップのフィルター、本格的なインベントリ、ドット絵の仕上げ、ボス、複数の階層、セーブ。

## 確認の仕方

- テスト：`godot --headless --script res://tests/run_tests.gd`
- 画面の撮影：`godot --script res://tools/capture/capture.gd -- --out=shots/now.png`（`--demo=attack` で斬撃中を撮る）
