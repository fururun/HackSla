# 企画の要点（AI向け）

元の企画書：ハクスラ企画書 コンセプトとゲームデザイン（claude.ai の文書）。
このファイルはその要点を、AIが読めるようにまとめたものです。食い違ったら企画書が正しい。

## コンセプト

自分で考えたビルドで、大量の敵を一気に倒す爽快感を味わうハクスラ。
弱い状態から始まり、レベル・スキル・ツリー・装備がそろうほど、群れを派手に蹴散らせるようになる。

- ジャンル：POE2やディアブロ型のアクションRPG（ハクスラ）
- 見た目：2Dドット絵、ファンタジー
- カメラ：斜め見下ろし（マップを45度回した、横2:縦1のアイソメトリック）。2Dドット絵ではディアブロ2の見た目が一番近い
- 最終目標：無限ダンジョン

## やらないこと（サバイバー系ローグライトにしない）

| 項目 | やらない | このゲーム |
| --- | --- | --- |
| 敵の出方 | 時間経過で周りから湧き続ける | マップに群れとして配置。プレイヤーが倒しに行く |
| 攻撃 | 自動攻撃 | 自分でスキルを使う |
| ビルド | レベルアップごとの選択肢から選ぶ | ジェム・ツリー・装備を自分で設計する |
| 成長 | 1回のプレイでリセット | キャラも装備もずっと残る |
| ドロップ | その場限りの強化 | 持ち帰って選別・クラフトする装備 |

参考作（POE2、ディアブロ、ルミナキューブなど）は「仕組み」だけ参考にする。名前・文章・数値・配置・絵は写さない。

## 成長の4段階

| 段階 | 状態 | 戦い方 |
| --- | --- | --- |
| 序盤 | 低レベル、スキル1〜2個、装備は貧弱 | 少数の群れを1体ずつ。位置取りが大事 |
| 中盤の入り口 | スキルが増え、ツリーの方向性が見える | 範囲攻撃で小さな群れをまとめて倒す |
| 中盤 | ツリーの大ノードとレア装備がそろう | 連鎖・撃破時の爆発で群れを一掃 |
| 終盤 | ビルド完成、クラフトで装備を詰める | 大群を一瞬で消し、深い階層へ |

一気に強くなる瞬間（新スキル、大ノード、ユニーク装備）を作り、敵の強さは少し遅れて追いかける。

## スキル

- **スキルジェム**：攻撃や魔法。手に入れてスキル装備画面ではめると使える
- **補助ジェム**：スキル枠の横の補助枠にはめると、そのスキルだけ性能が変わる（拡散、撃破時爆発など）
- **スキル装備画面**：キャラ専用。枠に上限がある（序盤はスキル枠2・補助0 → 終盤はスキル枠6・補助4〜5、仮）。枠はレベルの節目と階層ボスで増える
- **操作**：スキル枠1＝左クリック、2＝右クリック、3〜6＝Q/E/R/F。移動はWASD（画面基準の8方向）、スキルはマウスの方向へ
- **入手**：ドロップ・交換・ボス報酬（候補から選ぶ）。運任せにしない

### スキルチェイン（決定済み）

- 直前に使ったスキルが条件に合えば、次のスキルが「チェイン技」に変わる
- 受付時間は無制限。直前の1スキルだけを見る。間に別のスキルを挟むと無効
- 2段階まで（チェイン技の後は数え直し）
- 決まり方：タグ（属性×種類）の組み合わせ、または特定スキル同士の名前付きチェイン（こちらが優先）
- プレイヤーに発見させる。未発見のチェインは出さない。一度出したものはチェイン図鑑で確認できる（未発見は「？」で数だけ）
- 発見済みのチェインが出せるときだけ、スキル枠のアイコンが光る
- 実装：`scripts/skills/chain_tracker.gd`、データ：`data/chains/chains.json`

## スキルツリー

- ステータスとパッシブ専用（スキルを覚えたり、スキル枠を増やしたりはしない）
- レベルが1上がるごとに1ポイント。レベル自体ではステータスは上がらない
- 中央のスタートから枝のように伸びる。取れるのは、取ったノードとつながるノードだけ
- 小ノード（ステータス）、中ノード（戦い方に効くパッシブ）、大ノード（強い代わりに縛りがある）
- イメージはPOE2。実装前にPOE2の仕組みを調べて、このゲーム用に設計し直す（丸写ししない）
- ノード数：企画書では300前後。150〜200への見直しを検討中

## ドロップ・選別・クラフト

- 大量に倒すと大量に落ちる。通貨と素材は自動で拾い、装備は地面にこぼれる
- フィルターで表示を絞る → 残すか分解するか選ぶ → 素材で付与効果を振り直し・追加・固定
- レアリティは段階に分ける（数と名前は仮）。最上位2段階だけ光の柱と専用の音

## レベルデザインと演出

- 群れはマップに配置。広場と通路を交互に並べ、通路で引き込んで広場で一掃する
- 詰まりを作る敵：硬い単体、速い群れ、遠距離、属性耐性持ち
- 画面内の敵は100〜150体が目安。敵は物理演算を使わない軽い移動処理と、使い回し（プール化）が前提
- 演出：ヒットストップ、画面揺れ、撃破数、レアドロップの光の柱と効果音
- エフェクト素材：pixelfx（Claude Code用スキル付き）を基本に、スプライトシートで取り込む
