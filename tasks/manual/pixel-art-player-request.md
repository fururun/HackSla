# プレイヤーのドット絵を ChatGPT / Muse に頼む（手作業）

画像生成ができるAI（ChatGPT の画像生成、Muse のアプリ）に、プレイヤーのドット絵を作ってもらうための依頼文です。
できた画像は `art/sprites/player/` に保存して、Claude に「プレイヤーの絵を取り込んで」と頼んでください
（背景の除去、ドットの格子への整え、向きごとの切り分け、ゲームへの組み込みは Claude がやります）。

## 添付する画像（3つ）

1. **キャラクターの設定の絵**：`art/sprites/player/preview_front.png`（いまの侍の仮の絵。服・髪型・持ち物の確認用）
2. **雰囲気の参考**：ふるるん さんが見つけた「角の少女」のドット絵（細かさ・2頭身・大きな目・陰影の参考。キャラそのものは真似しない）
3. **キャラクターの参考**：ふるるん さんが見つけた「侍」の絵（黒髪ポニーテール、青緑の羽織、刀）

## 貼る依頼文

```
添付の画像を参考に、ゲーム用のドット絵のキャラクタースプライトを描いてください。

【キャラクター（これを描く）】
- 添付の「侍」の画像と同じキャラクター：黒髪を高い位置で結んだポニーテールの侍（少女）
- 青緑の羽織（袖と裾に白いぎざぎざの柄）、黒い胴当てに金の紋、白い帯、赤い前掛け付きの黒い袴
- 金の縁のすね当て、白足袋、左手に抜いた刀、右の腰に鞘
- 添付の「いまの仮の絵」は、服や持ち物の配置の確認用。顔や絵の細かさは、下の「雰囲気」に合わせて描き直してください

【ドット絵の雰囲気（添付の「角の少女」の画像のように）】
- 2頭身のデフォルメ、大きな目に光、全体に陰影、外側に1ドットの暗い輪郭線
- ただし、「角の少女」のキャラクターそのもの（角・銀髪・尻尾・長柄武器）は絶対に描かないこと

【条件】
- 斜め見下ろし視点のハクスラ用。全身が収まる絵
- 背景は透明の PNG。透明にできない場合は、単色の緑（#00FF00）の無地
- ドットの大きさを完全にそろえた本物のドット絵（アンチエイリアスなし、ぼかしなし、グラデーションなし）
- 1枚の大きさは 64×64 ドット前後に収まる粗さ。色数は16色以内
- 「正面（下向き）」「後ろ姿（上向き）」「右向き」の3枚を、同じキャラ・同じ大きさ・同じ足元の位置で、横に並べた1枚の画像にする
- 足元の位置（地面に立つ位置）は、3枚とも同じ高さの、画像の下端近くにそろえる
```

## うまくいかないとき

| 症状 | 頼み直し方 |
| --- | --- |
| ドットがぼやける・大きさがばらつく | 「ドットの大きさを完全にそろえて。拡大したときに、1ドットが正方形の格子に乗っていること」と伝える |
| 3枚の見た目が違う | 「正面の絵を基準に、同じ服・同じ髪型・同じ大きさで、後ろ姿と右向きを描いて」と伝える |
| 角の少女に寄りすぎる | 「角・銀髪・尻尾は描かない。キャラクターは侍。雰囲気（細かさ）だけ参考にして」と伝える |
| 背景が透明にならない | 「背景を #00FF00 の無地にして」と伝える（Claude が透明に直せる） |

## 取り込みのあと（Claude の作業）

1. 背景の除去、ドットの格子への整え（元の大きさへの縮小、色数の整理）
2. 3枚への切り分け、足元の位置そろえ
3. `art/sprites/player/player_front.png` `player_back.png` `player_side.png` と差し替え、`player.gd` の絵の大きさを合わせる
4. 撮影して、見え方を確認

## メモ

- 敵・宝箱・装備のアイコンなども、同じ頼み方で作れる。最初の絵を「同じ画風で」と添付すると、画風がそろう。
- 作った画像の利用条件（商用利用の可否）は、各サービスの規約を確認すること。
