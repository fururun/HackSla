# 侍の「斜め向き」の絵を ChatGPT / Muse に頼む（手作業）

いまの侍の絵は「正面・後ろ・右向き」の3枚だけです。斜めに歩くときも、この3枚のどれかを使うので、
体の向きと歩く向きが合って見えません。斜めの絵を足すと、8方向すべてで向きが合います。

## 足りない絵（2枚。残りは左右反転で作ります）

| 絵 | 向き | 反転で作れるもの |
| --- | --- | --- |
| 斜め前（右下向き） | 画面の右下に向かって歩く。顔が見え、体は右下に向く | 左下向き |
| 斜め後ろ（右上向き） | 画面の右上に向かって歩く。背中が見え、体は右上に向く | 左上向き |

すでにある3枚（正面＝下、後ろ＝上、右向き＝右。左は右の反転）と合わせて、8方向になります。

## 添付する画像

1. いまの侍の3枚：`art/sprites/player/source/hacksla_samurai_sprite_3views_topdown_source.png`（同じ見た目にそろえるお手本）

## 貼る依頼文

```
添付の画像は、同じキャラクターの「正面」「後ろ姿」「右向き」の3枚です。
同じキャラクター・同じ服・同じ髪型・同じ画風・同じ大きさ・同じ足元の位置で、次の2枚を描き足してください。

1. 「斜め前（右下向き）」：画面の右下に向かって歩いている姿。顔が見え、体と足が右下に向いている。刀と鞘の位置は、3枚と同じ向きの持ち方にそろえる
2. 「斜め後ろ（右上向き）」：画面の右上に向かって歩いている姿。背中が見え、体と足が右上に向いている。後ろに流れるポニーテールと、背中の鞘が見える

条件:
- 背景は透明の PNG。透明にできない場合は、単色の緑（#00FF00）の無地
- ドットの大きさを完全にそろえた本物のドット絵（アンチエイリアスなし、ぼかしなし、グラデーションなし）
- 添付の3枚と、ドットの粗さ・輪郭線・陰影・色づかいを完全にそろえる
- 2枚を横に並べた1枚の画像にする。足元の位置は、2枚とも同じ高さにそろえる
```

## うまくいかないとき

| 症状 | 頼み直し方 |
| --- | --- |
| 向きが違う（正面のまま、横向きのまま） | 「体全体が、画面の右下（右上）の方向に45度回っている姿で」と伝える |
| 服や髪が変わる | 「添付の正面の絵と、色・服・髪型を完全に同じにして」と伝える |
| 大きさがそろわない | 「頭のてっぺんから足元までの高さを、添付の正面と同じにして」と伝える |

## 取り込みのあと（Claude の作業）

1. 背景の除去、ドットの格子への整え、30×30 への縮小（いまの3枚と同じやり方）
2. 足元の位置そろえ
3. `player_diag_down.png`（右下）・`player_diag_up.png`（右上）として保存し、8方向の切り替えを `scripts/player/player.gd` の `view_for` に反映
4. 撮影して、8方向で向きが合っていることを確認

## メモ

- 岩殻など他の敵は、向きが1つ（正面）だけなので、いまのままで足ります。必要になったら、同じ頼み方で足せます。
