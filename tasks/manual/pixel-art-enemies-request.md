# 敵・宝箱などのドット絵を ChatGPT / Muse に頼む（手作業）

侍（`pixel-art-player-request.md` で作ってもらったもの）と同じ画風で、残りの絵を作ってもらうための依頼書です。
できた画像は `art/sprites/incoming/` などに保存して、Claude に「○○の絵を取り込んで」と頼んでください
（背景の除去、ドットの格子への整え、ゲームの大きさへの縮小、組み込みは Claude がやります）。

## 作ってもらうもの（優先順）

| 順 | 絵 | ゲームでの大きさ（目安） | 向き | 補足 |
| --- | --- | --- | --- | --- |
| 1 | **岩殻**（硬くて遅い岩の魔物。雑魚より大きい） | 幅 22 × 高さ 22 ドット | 正面・後ろ・右向き | 岩を積んだ巨体。小さな光る目。腕は岩のかたまり |
| 2 | **宝箱** | 幅 18 × 高さ 14 ドット | 閉じた状態・開いた状態の2枚 | 木の箱に金具。開いた絵は蓋が後ろに倒れ、中が暗い |
| 3 | **案山子**（倒れない練習用の的） | 幅 16 × 高さ 30 ドット | 正面のみ | 棒と十字の腕、丸い頭、藁の質感 |
| 4 | **ドロップのアイコン**（地面に落ちるもの） | 8 × 8 ドット前後 | 1枚ずつ | ジェム（スキル用・補助用の2色）、装備（武器・防具・指輪の3種）、通貨の硬貨 |

スライム（雑魚敵）は、ふるるん さんの参考画像に合わせて、すでにコードで作ってあります。同じ画風にそろえたいので、スライムの画像も添付してください。

## 添付する画像

1. 侍の絵：`art/sprites/player/source/hacksla_samurai_sprite_3views_topdown_source.png`（画風のお手本）
2. スライムの参考画像（ふるるん さんが見つけたもの。縁が明るく、本体が濃い、紺の影がある平たい半球）
3. 描いてほしい物の参考（あれば）

## 貼る依頼文（共通の前置き）

```
ゲーム用のドット絵のスプライトを描いてください。添付の「侍」の画像と同じ画風にしてください。

【画風（添付の侍とスライムのように）】
- 2頭身のデフォルメ寄りの、かわいらしく少し丸みのある絵
- 全体に陰影（明るい面・暗い面）、つや（ハイライト）、外側に1ドットの暗い輪郭線
- 斜め見下ろし視点のハクスラ用（敵は、こちらを向いた正面が基本）
- 色は落ち着いた暗い背景（石畳の床）で映える、はっきりした色

【条件】
- 背景は透明の PNG。透明にできない場合は、単色の緑（#00FF00）の無地
- ドットの大きさを完全にそろえた本物のドット絵（アンチエイリアスなし、ぼかしなし、グラデーションなし）
- 色数は16色以内。全体が収まる絵
- 向きが複数ある絵は、同じキャラ・同じ大きさ・同じ足元の位置で、横に並べた1枚の画像にする
- 既存のゲームの敵・キャラクターの名前・絵は真似しない
```

## 続けて貼る、絵ごとの依頼文

### 1. 岩殻

```
描いてほしいもの：「岩殻（いわがら）」。硬くて動きの遅い、岩でできた魔物。
- 岩を積み重ねた、横幅のある丸っこい巨体。肩と腕は大きな岩のかたまり
- 顔は岩の面に、小さく光る目（淡い黄色）だけ
- 色は灰色がかった青（岩）を基調に、明るい面・暗い面で立体感を出す
- 足元は短い岩の脚。地面に重く立っている
- 「正面」「後ろ姿」「右向き」の3枚を横に並べる。ゲームでの大きさは幅22×高さ22ドット程度（雑魚のスライムの倍くらい大きく見える）
```

### 2. 宝箱

```
描いてほしいもの：「宝箱」。木の箱に金具が付いたもの。
- 「閉じた宝箱」と「開いた宝箱」の2枚を横に並べる
- 閉じた絵：丸みのある蓋、中央に金の錠前、四隅と帯に金具
- 開いた絵：蓋が後ろに大きく開き、中は暗い。ほのかに金色の光がこぼれる
- ゲームでの大きさは幅18×高さ14ドット程度
```

### 3. 案山子

```
描いてほしいもの：「案山子（かかし）」。倒れない練習用の的。
- 縦の棒に、横の棒（腕）を十字に組み、藁の服、丸い頭（布袋）
- 藁の質感が分かる細かい縦線、頭には素朴な顔（点の目と口）
- 「正面」の1枚だけ。ゲームでの大きさは幅16×高さ30ドット程度
```

### 4. ドロップのアイコン

```
描いてほしいもの：地面に落ちているアイテムのアイコン（小さな絵）。1つずつ、整列した見本帳のように並べる。
- スキルジェム：丸みのある宝石（赤みのある色）
- 補助ジェム：スキルジェムと形は似て、色だけ青
- 装備：剣（武器）、胴の防具、指輪の3つ
- 通貨：金色の硬貨
- 1つの大きさは 8×8 ドット前後。輪郭線を付け、つやを1点入れる
```

## うまくいかないとき

| 症状 | 頼み直し方 |
| --- | --- |
| ドットがぼやける・大きさがばらつく | 「ドットの大きさを完全にそろえて。1ドットが正方形の格子に乗っていること」 |
| 侍と画風が違う | 「添付の侍と同じ、輪郭線・陰影・つやの描き方で、描き直して」 |
| 大きさの比が合わない | 「侍の高さを 100 としたとき、岩殻は 75、宝箱は 45、案山子は 100 の高さで」 |
| 背景が透明にならない | 「背景を #00FF00 の無地にして」（Claude が透明に直せる） |

## 取り込みのあと（Claude の作業）

1. 背景の除去、ドットの格子への整え（元の大きさへの縮小、色数の整理）。侍の絵と同じやり方
2. 向きごとの切り分け、足元の位置そろえ
3. `scripts/enemies/enemy.gd`（敵）、`scripts/world/treasure_chest.gd`（宝箱）、`scripts/enemies/training_dummy.gd`（案山子）、`scripts/loot/ground_drop.gd`（ドロップ）の絵を差し替え
4. 撮影して、見え方と大きさのそろえを確認

## メモ

- 敵の絵を画像にしたときも、150体が同時に出るので、1体の絵は**使い回し**（同じ画像を何度も描く）で動かす。
- 作った画像の利用条件（商用利用の可否）は、各サービスの規約を確認すること。
