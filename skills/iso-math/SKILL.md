# 斜め見下ろし視点（アイソメトリック、横2:縦1）の計算

- 地面の距離は `Iso.ground_distance(a, b)`（画面の縦を2倍にして測る）
- 地面の円の中か：`Iso.in_ground_circle(中心, 点, 半径)`
- 扇形の当たり判定：`Iso.in_ground_arc(原点, 向き, 点, 半径, 半分の角度)`
- 地面の円を画面に描くときは、縦を0.5倍した楕円にする
- キャラの向きは `Facing`（8方向）。絵は5方向だけ描き、左側は左右反転
- マップの座標と画面の座標の変換は `TileMapLayer.map_to_local()`
