# 使い回し（プール化）の作り方

1. 消えたものは `queue_free()` せず、非表示にしてプールに戻す
2. 出すときはプールから取り出し、位置と状態を初期化して表示する
3. プールが空なら新しく作る（上限を const で決める）
4. 敵に物理演算（CharacterBody2D / RigidBody2D / Area2D）を使わない
5. 敵同士の押し合いは、マス目に分けて近くだけ比べる（全員×全員はしない）
6. テストで「消えたものがプールに戻る」「プールから再利用される」を確かめる
