# 参考作の分析の手順（丸写し禁止の確認表付き）

1. 調べる対象と、このゲームのどこに使うかを先に書く
2. 仕組みごとに「プレイヤーが何を楽しんでいるか」を書く
3. 出典のURLを各項目に付ける。推測や記憶は「未確認」と書く
4. このゲームへの提案：何を残し、何を削るか（`docs/concept.md` の規模に合わせる）
5. 丸写し禁止の確認表（すべて「写していない」こと）
   - 固有の名前（スキル名、ノード名、アイテム名）
   - 文章（説明文、フレーバーテキスト）
   - 具体的な数値の組み合わせ
   - 配置や座標（ツリーの形そのもの）
   - アイコン・絵・画面のデザイン
