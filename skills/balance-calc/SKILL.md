# 数値の裏付けの計算（DPS表と倒すまでの時間）

1. DPS（1秒あたりのダメージ）＝ 1回のダメージの平均 ÷ 再使用時間
   - 範囲攻撃は「当たる敵の数」を掛けた値も出す
   - 補助ジェムは倍率と追加の数を反映する
2. 倒すまでの時間 ＝ 敵の最大ライフ ÷ DPS
3. 表にする：スキル単体 / 補助あり / チェインあり × 群れ小鬼 / 岩殻
4. 指示書の目安ごとに「満たしている／いない」と計算を書く
5. ダメージの計算式は `scripts/stats/damage_calc.gd`（耐性・防御）に合わせる
